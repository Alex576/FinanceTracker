ТЗ: Интерфейс системы управления личными финансами
1. Общая концепция
Создание адаптивного веб-интерфейса для отслеживания бюджетов с использованием визуальных индикаторов состояния и интерактивных элементов аналитики.

4. Функциональные требования

    4.1. Система уведомлений «Светофор»
    Цвет полосы прогресса (Progress Bar) на карточках:
    - Зеленый (#2ECC71): Расход < 50% от лимита.
    - Желтый (#F1C40F): Расход 51% – 85% (Предупреждение).
    - Красный (#E74C3C): Расход > 100% (Перебор).

    4.2. Форма создания записи (Модальное окно)
    Должна содержать следующие поля:
    - Тип: Toggle-переключатель (Расход / Доход).
    - Сумма: Числовое поле с поддержкой валют.
    - Категория: Выпадающий список с иконками.
    - Дата: Селектор даты (по умолчанию текущая).
    - Заметка: Текстовое поле для комментария.

    4.3. Механика Drag & Drop
    Виджеты графиков в правой панели должны иметь «хендл» (иконка ::) для захвата   мышью.
    Пользователь может менять порядок графиков, приоритезируя важную информацию.

Ключевые элементы этой схемы:
1. Левая панель (Палитра + Слои):
    - Сверху — иконки компонентов, которые можно перетащить на холст.
    - Снизу — дерево элементов, чтобы быстро найти «потерявшуюся» кнопку или увидеть вложенность.
2. Центр (Холст):
   - Сетка (Grid): Фоновая сетка помогает выравнивать элементы.
   - Выделение: Выбранная таблица обведена синей рамкой с маркерами по углам для изменения размера.
3. Правая панель (Инспектор):
    - Аккордеоны: Разделы «Основные», «Колонки», «Стили» раскрываются по клику, чтобы не загромождать экран.
    - Список колонок: Внутри раздела «Колонки» можно менять их местами, просто перетаскивая строчки за иконку ::

Особенности для Input-поля в редакторе:
1. Интерактивные «якоря» на холсте:
    - Когда поле выделено, вокруг него появляются точки. Если потянуть за правую — меняется ширина.
    - Появляется маленькая плавающая кнопка «Дублировать» или «Удалить» прямо над полем.
2. Специфические настройки в правой панели:
    - Placeholder: Текст-подсказка, который виден внутри поля, пока пользователь ничего не ввел.
    - Тип данных: Можно переключить «Текст» на «Пароль» (символы станут точками) или «Email».
    - Валидация: Блок, где можно поставить галочку «Обязательно» (Required) и настроить текст ошибки (например: «Пожалуйста, заполните это поле»).
3. Иконки (Slots):
    - Возможность добавить иконку внутрь поля (например, иконку лупы для поиска или замочка для пароля) простым выбором из библиотеки.
4. Состояния (States):
    - В разделе Стили можно переключить вид на «Ошибка» (красная рамка) или «Фокус», чтобы заранее настроить, как поле будет реагировать на действия юзера.

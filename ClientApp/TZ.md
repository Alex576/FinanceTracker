4. Функциональные требования

    4.1. Система уведомлений «Светофор»
    Цвет полосы прогресса (Progress Bar) на карточках:
    - Зеленый (#2ECC71): Расход < 50% от лимита.
    - Желтый (#F1C40F): Расход 51% – 85% (Предупреждение).
    - Красный (#E74C3C): Расход > 100% (Перебор).

    4.2. Форма создания записи (Модальное окно)
    Должна содержать следующие поля:
    - Тип: Toggle-переключатель (Расход / Доход).
    - Сумма: Числовое поле с поддержкой валют.
    - Категория: Выпадающий список с иконками.
    - Дата: Селектор даты (по умолчанию текущая).
    - Заметка: Текстовое поле для комментария.

    4.3. Механика Drag & Drop
    Виджеты графиков в правой панели должны иметь «хендл» (иконка ::) для захвата   мышью.
    Пользователь может менять порядок графиков, приоритезируя важную информацию.
